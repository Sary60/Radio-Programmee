Radio Programmée V1.1 Premium

Interface sombre, sélection immédiate des stations, volume, programmations conservées.

Installer avec Termux : unzip -o Radio-Programmee-V1.1-Premium.zip -d /tmp/radio-v11 ; cp -r /tmp/radio-v11/Radio-Programmee/. ~/radio-github/ ; cd ~/radio-github ; git add . ; git commit -m "Radio V1.1 Premium" ; git push origin HEAD

Les logos sont des monogrammes stylisés (pas encore les logos officiels). Les flux radio tiers peuvent changer ou être indisponibles.
